# Λογική Υπολογισμού Μισθοδοσίας — Βήμα-Βήμα

⚠️ Τα ποσοστά αλλάζουν. Κάνε web search για τρέχοντα ποσοστά ΕΦΚΑ πριν υπολογίσεις.

---

## Από Μεικτό σε Καθαρό (Εργαζόμενος)

### Βήμα 1: Εισφορές Εργαζομένου
Οι εισφορές αφαιρούνται από το μεικτό μισθό:

| Κλάδος | Ποσοστό (επαλήθευε) |
|---|---|
| Κύρια σύνταξη | ~6,67% |
| Επικουρική σύνταξη | ~3,25% |
| Υγεία (ασθένεια σε είδος) | ~2,15% |
| Υγεία (ασθένεια σε χρήμα) | ~0,40% |
| **Σύνολο εργαζόμενου** | **~13,87%** |

### Βήμα 2: Φόρος Εισοδήματος
Εφαρμόζεται στο **μεικτό μείον εισφορές**:

| Εισόδημα/έτος | Συντελεστής |
|---|---|
| €0 – €10.000 | 9% |
| €10.001 – €20.000 | 22% |
| €20.001 – €30.000 | 28% |
| €30.001 – €40.000 | 36% |
| €40.001+ | 44% |

⚠️ Η κλίμακα ισχύει για ετήσιο εισόδημα — ο μηνιαίος φόρος είναι το 1/12 του ετήσιου.
Επαλήθευε πάντα μέσω search — η κλίμακα αλλάζει.

### Βήμα 3: Καθαρός Μισθός
```
Καθαρός = Μεικτός − Εισφορές Εργαζόμενου − Φόρος Εισοδήματος
```

---

## Κόστος Εργοδότη

Εκτός από το μεικτό μισθό, ο εργοδότης πληρώνει επιπλέον εισφορές:

| Κλάδος | Ποσοστό (επαλήθευε) |
|---|---|
| Κύρια σύνταξη | ~13,33% |
| Επικουρική σύνταξη | ~3,25% |
| Υγεία (είδος) | ~4,30% |
| Υγεία (χρήμα) | ~0,25% |
| Επαγγελματικός κίνδυνος | ~1,00% |
| **Σύνολο εργοδότη** | **~22,13%** |

```
Συνολικό κόστος εργοδότη = Μεικτός × (1 + 22,13%)
```

**Παράδειγμα**: Μεικτός €1.500 → Κόστος εργοδότη ≈ €1.832

## Δώρα & Επιδόματα

### Δώρο Χριστουγέννων
- = 1 μηνιαίος μισθός (αν εργάστηκε ολόκληρο το διάστημα 1/5 – 31/12)
- Καταβάλλεται έως 21 Δεκεμβρίου

### Δώρο Πάσχα
- = 1/2 μηνιαίος μισθός (διάστημα 1/1 – 30/4)
- Καταβάλλεται έως Μεγάλη Τετάρτη

### Επίδομα Αδείας
- = 1/2 μηνιαίος μισθός (δικαιούται μετά από 1 έτος)
- Καταβάλλεται κατά τη λήψη άδειας

## Τι Στέλνεις στον Λογιστή για Μισθοδοσία

Κάθε μήνα:
```
□ Ώρες εργασίας (αν αμείβεται ωριαία)
□ Τυχόν υπερωρίες
□ Άδειες / απουσίες
□ Τυχόν αλλαγές στις αποδοχές
□ Νέες προσλήψεις ή αποχωρήσεις
```

Ο λογιστής υποβάλλει:
- ΑΠΔ (Αναλυτική Περιοδική Δήλωση) στον e-ΕΦΚΑ
- Έντυπο Ε4 (αν υπάρχει αλλαγή) στο ΕΡΓΑΝΗ
- Μισθοδοτικές καταστάσεις για το αρχείο
