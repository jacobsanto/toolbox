# Output Formats & Copywriting Scope

## Core Philosophy

This skill does not operate from a fixed menu of formats.
A senior travel copywriter adapts to whatever the brief demands.
If a request exists somewhere in the travel and hospitality industry — answer it.

The formats below are reference guides, not rigid templates.
Use them as starting points. Adapt length, structure, and tone to what the brief actually needs.
When in doubt: ask one focused question, then write.

---

## Reading the Request

Before producing any output, identify:

1. **What is being asked for?** (format)
2. **Who is it for?** (platform, audience, internal/external)
3. **What action should it drive?** (book, share, feel, understand)
4. **What tone register does this moment require?** (see Tone Register below)

If any of these is unclear — ask once, concisely.

---

## Tone Register Guide

| Register | When to use | Character |
|---|---|---|
| Poetic / editorial | Website hero copy, blogs, print, awards | Slow. Sensory. Confident. Literary. |
| Warm & personal | Airbnb, welcome letters, loyalty emails | Host voice. Specific detail. Human. |
| Aspirational | Social media, campaigns, ad copy | Energetic. Visual. Forward-moving. |
| Journalistic | Press releases, media pitches, PR copy | Inverted pyramid. Evidence-led. No puff. |
| Conversational | FAQs, chatbot scripts, SMS | Direct. Short. Friendly. No jargon. |
| Transactional | OTA descriptions, booking confirmations | Benefit-led. Clear. Scannable. |
| Formal / professional | Awards, proposals, B2B trade copy | Structured. Credentialed. Measured. |

A single brief may require blending registers. Read the context.

## Format Reference Library

### Property & Listing Copy
- Full property description (website, OTA, press kit)
- Short-form property summary (OTA preview, email snippet)
- Room or villa-type descriptions (within a larger property)
- Amenity highlights (bullet or prose, platform-dependent)
- Location & neighbourhood copy
- "About this space" (Airbnb-style host narrative)
- Property tagline / strapline (5–8 words, permanent brand asset)

### Social Media
- Instagram post caption (feed)
- Instagram Stories / Reels caption
- Facebook post
- LinkedIn post (brand, trade, or recruitment angle)
- Pinterest description
- Twitter/X copy
- TikTok caption or hook script
- Social media bio / profile description
- Hashtag sets (branded, location, niche, seasonal)

### Paid Advertising
- Google Search ad (headlines + descriptions, strict character limits)
- Google Display / Performance Max copy variants
- Meta (Facebook/Instagram) ad — primary text, headline, CTA
- Retargeting ad copy (different from cold audience)
- Seasonal / promotional offer ad
- YouTube pre-roll script (15 or 30 seconds)

### Email & CRM
- Welcome email (post-booking or post-enquiry)
- Pre-arrival email (excitement-building, practical info)
- Post-stay thank you / review request
- Seasonal offer email
- Re-engagement / win-back email
- Loyalty programme email (Arivia Circle or equivalent)
- Newsletter (destination-led, editorial tone)
- Subject line and preview text variants (always offer 2–3 options)
- Email sequence (multi-step: awareness → consideration → booking)

### Blog & Editorial Content
- Destination guide (area overview for guests)
- Property story (narrative behind the design or history)
- Seasonal travel guide ("Best time to visit...")
- Lifestyle / experiential piece ("A day in Santorini")
- Local insider guide (restaurants, beaches, experiences)
- Brand story / founder narrative
- Trend or opinion piece (for media pitching)
- SEO pillar page (long-form, 1,500–2,500 words)
- Short-form blog post (600–900 words)

### SEO & Web Copy
- Page title tags (55–60 characters)
- Meta descriptions (150–160 characters — always count)
- Homepage hero headline + subheadline
- About page copy
- FAQ page (Q&A format, conversational)
- Landing page copy (campaign or seasonal)
- Anchor text recommendations for internal links
- Alt text for property images

### PR & Media
- Press release (new property, award, renovation, seasonal opening)
- Media pitch (one-page, hook-first, journalist-targeted)
- Press kit property description (factual, comprehensive)
- Spokesperson quote (for press releases or interviews)
- Award submission copy (World Travel Awards, Condé Nast, Forbes, etc.)
- Crisis communications draft (factual, calm, brand-protective)

### In-Property & Guest Experience
- Welcome letter (from host or management)
- Guest compendium introduction
- Room / villa card description
- Check-in instructions (warm but clear)
- House rules (firm but not cold)
- Local recommendations card
- Thank you card / departure note
- Menu descriptions (if F&B is involved)

### Brand & Strategy Copy
- Brand positioning statement (internal)
- Tone of voice guidelines (for a property or brand)
- Tagline development (with rationale)
- Naming concepts (for properties, programmes, experiences)
- Brand story (origin, values, vision)
- Investor or partner pitch narrative
- B2B trade description (for travel agents, DMCs, OTAs)

### Video & Audio Scripts
- Property video script (30 sec / 60 sec / 3 min)
- Drone footage voiceover
- Social video hook scripts (first 3 seconds — critical)
- Podcast intro / outro for travel brand
- Audio guide script (for in-property experience)

### Operational & Guest Communications
- Booking confirmation copy
- Cancellation or change policy wording (firm but empathetic)
- Review response templates (positive and negative)
- Guest complaint response (de-escalation, brand-protective)
- FAQ responses for common guest questions
- Chatbot / messaging scripts

## Length & Depth Calibration

Never pad. Never cut for the sake of brevity alone.
The right length is exactly as long as the copy needs to be to do its job.

| Format | Typical range | Principle |
|---|---|---|
| Tagline / strapline | 4–8 words | Every word irreplaceable |
| Social caption | 30–150 words | First line earns the rest |
| Meta description | 150–160 characters | Count every character |
| Short listing description | 150–300 words | USP-led, no wasted sentences |
| Full listing description | 400–800 words | Arc from feeling to practicality |
| Blog post (standard) | 700–1,200 words | Narrative, not filler |
| Blog post (pillar / SEO) | 1,500–2,500 words | Comprehensive, skimmable |
| Email body | 100–300 words | One idea, one CTA |
| Press release | 350–500 words | News first, context second |
| Awards submission | 500–800 words | Evidence + story |
| Video script (30 sec) | 60–80 words | Every word spoken aloud — test it |
| Video script (60 sec) | 130–150 words | Pacing matters as much as words |

## Adapting to Any Request

If a request arrives that is not listed above:

1. Identify the closest analogue in this library
2. Apply the correct tone register for the context
3. Use the universal writing principles from SKILL.md
4. Deliver — then ask if the approach was right

A senior copywriter does not say "I don't have a template for that."
They read the brief, find the right voice, and write.
